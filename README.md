# Bravarska radionica — modelovanje sistema

Studentski projekat iz predmeta **Životni ciklus softvera**. Projekat predstavlja specifikaciju i modele informacionog sistema za upravljanje poslovima bravarske radionice.

## Sadržaj

- `Bravarska radionica.docx` — specifikacija softverskih zahteva, korisničkih uloga i poslovnih procesa;
- folder `Bravarska radionica/` — PowerDesigner projekat, modeli i dijagrami za uloge klijenta, majstora, šefa radionice i administratora;
- `Bravarska radionica/crebas.sql` — skripta za strukturu baze podataka u SAP SQL Anywhere 17.

Dokumentacija obrađuje prijem zahteva, predračune, radne naloge i praćenje njihovog statusa.

## Otvaranje

Dokument se otvara programom koji podržava `.docx`. Modeli se otvaraju u SAP PowerDesigner-u. SQL skripta je namenjena za SAP SQL Anywhere 17.

**Napomena:** repozitorijum sadrži specifikaciju, modele i SQL skriptu, a ne implementiranu web ili mobilnu aplikaciju.
